You can check this hacky experiment out [here](https://www.iwanttobuildthis.com/).

I got this meta idea on a walk where I was trying to figure out what to build. What if there was a tool that allowed me to validate ideas before investing to much dev time into them?

I Want To Build This is essentially a landing page email capture tool but with a gamification element where you can select a subscriber target and only build if you get that many emails. So sort of like kickstarter except users are giving you their email instead of money.

You can check this hacky experiment out [here](https://www.iwanttobuildthis.com/).
