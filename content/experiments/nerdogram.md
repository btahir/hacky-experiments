Nerdogram is an open source, very original, photo sharing app that is exclusive to folks who have a Github account i.e. you can only sign up if you have one.&#x20;

## Why

Why not? Let's make nerds cool again by sharing photos of our favorite Github projects. A picture is worth a thousand lines of code as they say.

## [](https://github.com/btahir/nerdogram#the-tech)The Tech

- Next.js + Tailwind CSS
- Next-Auth + Github OAuth for authentication
- Heroku Postgres SQL Database to store the data
- Cloudinary to store images
- Prisma to interact with the data
- Vercel to deploy site on
- Font Awesome Icons

You can check this hacky experiment out [here](https://github.com/btahir/nerdogram).
