Snoop Hawk lets you automate web research. Think Zapier but for manual tasks which involve going to a website any checking things (design review after a change, competitor analysis etc). Or if you're more technically inclined, a visual unit test.

You basically setup jobs which you can run now or schedule later that will instruct an AI to go to a website and answer your specified questions. You can even get an email notification based on the answers!

Very cool and powerful stuff. :)
